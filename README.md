Проект представляет собой систему для устойчивого и точного обнаружения объектов с повторяющимися геометрическими признаками (металлических труб) на изображениях
Наше решение можно использовать как инструмент для рабочих, мастеров и инженеров на металлургическом предприятии, в ситуациях когда нужно быстро посчитать количество и тип изготовленных труб.
